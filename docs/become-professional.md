# Apredizado profissional

**Desafio**

- Antes, o projeto utilizava um fluxo de versionamento linear diretamente na branch principal. Isso
  gerava riscos de quebrar o código de produção a cada nova alteração e dificultava o rastreamento
  de bugs.

**GitFlow**

- Para profissionalizar o ciclo de vida do software, implementei o modelo GitFlow. Criei a branch
  estável develop como base para o desenvolvimento e adotei a boa prática de isolar cada nova
  funcionalidade em branches feature/.

**Apredizagem prática**

- Durante esse processo, compreendi a importância do isolamento de código para garantir a segurança
  da aplicação. Além disso, para otimizar o trabalho no terminal e criar memória muscular,
  configurei Aliases personalizados do Git (git cob, git cm), unindo a velocidade da automação ao
  controle total de cada comando executado por baixo dos panos.
